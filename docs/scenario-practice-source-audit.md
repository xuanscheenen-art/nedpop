## Scenario Design Rules

- A0 scenarios are survival inputs: greeting, name, residence, language ability, numbers, classroom help, food/drink, time.
- A1 scenarios build foundation domains: personal forms, family, home, supermarket, cafe, transport, directions, weather/clothes, work/school, simple health, neighborhood.
- A2 scenarios train exam-like and civic-life output: task instructions, appointments, GP, pharmacy, municipality, housing repair, sick leave, shopping service, transport delay, bills/insurance, email, phone repair, school/child communication, job application, past events, reasons, integrated simulation.
- Do not copy source exercises. Use source topic coverage and task type only.
- Every scenario should include useful words, useful phrases with learner-facing meaning, a short dialogue with translation, and one speaking output. A2 scenarios should usually include a writing output.
