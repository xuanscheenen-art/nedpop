# NedPop Curriculum Source Map

Purpose: collect safe and useful public reference sources for designing NedPop's Dutch syllabus.

These sources are used only to understand level scope, topic coverage, grammar progression, exam task types, and exercise formats. Do not copy textbook text, exercises, audio, images, workbook pages, or official exam questions.

## 1. Official Exam / Integration References

### DUO / Inburgeren Official Practice Exams

- Source: [Taking the exam: Practicing - DUO Inburgeren](https://inburgeren.nl/en/taking-the-integration-exam/practicing.jsp)
- Use for:
  - A2 exam task format.
  - Speaking, writing, listening, reading task types.
  - Knowledge of Dutch Society / KNM topic awareness.
  - General understanding of what learners need to do in integration-style tasks.
- Do not use for:
  - Copying official questions.
  - Reusing official prompts, answers, audio, images, or PDFs.
  - Presenting NedPop content as official DUO exam content.

### Naar Nederland Official Self-Study Package

- Source: [Naar Nederland self-study package](https://naarnederland.nl/en-GB/self-study-package)
- Related source: [Learning for the exam - Naar Nederland](https://www.naarnederland.nl/en-GB/learning-for-the-exam)
- Use for:
  - A0/A1 beginner structure.
  - Very basic Dutch expressions.
  - Basic civic integration preparation.
  - Understanding how absolute beginners are guided toward simple Dutch and society topics.
- Do not use for:
  - Copying workbook pages.
  - Copying audio directly.
  - Reusing official exercises or film content.

## 4. Avoid / High-Risk Sources

Avoid using these as product sources:

- Scribd uploaded 教材 PDFs.
- Studeersnel uploaded materials.
- Random scanned commercial textbooks.
- Unofficial Google Translate audio scraping.
- Reuploaded workbook answer keys.
- Any source where copyright ownership or redistribution rights are unclear.

Use for: do not use as product source.

## Final Content Policy

NedPop should create original content based on:

Decode → Link → Rule → Speak.

All word associations, Chinese memory hooks, grammar cards, quizzes, scenario dialogues, and audio should be original or generated by our own pipeline.

Reference sources can inform scope, level boundaries, topic coverage, task formats, and difficulty calibration. They must not become copied lesson content.
