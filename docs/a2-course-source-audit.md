## A0 / A1 / A2 Position

- A0 is not an official CEFR exam target. It is a pre-A1 survival scaffold for pronunciation, greetings, numbers, personal information, classroom repair phrases, and first self-introduction.
- A1 is a foundation layer. It overlaps with beginner and basic civic-integration preparation, especially personal information, family, time, shopping, transport, housing words, and simple health language.
- A2 is the real exam-oriented language target for this course track. It must explicitly train reading, listening, speaking, and writing tasks, plus routine public-service situations.

## Course Design Rules

- Do not copy DUO/Naar Nederland/NT2 questions, text, audio, images, or workbook activities.
- Use public sources only to decide what learners should be able to do.
- Every A2 lesson should map to at least one of these tasks: read a short practical text, listen for key information, speak in a service interaction, fill a form, or write a short message.
- A0/A1 can prepare vocabulary and sentence patterns, but should not pretend to be the final inburgering language level.
